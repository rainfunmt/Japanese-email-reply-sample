# 日文書信帖

日文商務書信草稿產生工具。依「情境類型」「對象關係」「正式/委婉程度」自動套用預先撰寫好的日文範本，協助快速產出可直接編輯、符合商務禮儀的日文書信草稿。

純前端網頁，單一 HTML 檔案即可執行，不需安裝、不需後端、不需串接任何 API。

## Demo

開啟 [`index.html`](./index.html) 即可直接使用。操作流程：

1. 在「想表達的事」輸入想說的內容（中文或英文皆可，僅供你自己對照填空用）。
2. 選擇「情境類型」：道歉／報價／催交期／拒絕。
3. 選擇「對象關係」：初次接觸／長期往來客戶／上級或重要客戶。
4. 選擇「正式/委婉程度」：一般丁寧／更委婉謙讓／嚴肅鄭重。
5. 視情境選填「原因/補充說明類型」與對應欄位（例如報價的有效期限、催交期的原訂交期與新交期、拒絕的具體原因），系統會把對應的日文句子自動代入範本。
6. 點擊「產生日文草稿」，即可取得完整日文草稿，並附上敬語等級標註與可依關係調整的建議。
7. 草稿可直接編輯，確認內容後按「複製」即可貼上使用。

### 範例

**輸入**

- 想表達的事：因為我司排程已滿、數量超出目前產能，無法承接這筆訂單
- 情境類型：拒絕
- 對象關係：初次接觸
- 正式/委婉程度：一般丁寧
- 原因/補充說明類型：訂單數量超出承接能力

**輸出**

```
件名：ご提案についてのご回答
```

## 特色

- **零 AI、零外部 API**：所有日文內容皆為手寫範本，輸出固定、可預期，不會有 AI 生成內容忽好忽壞的問題。
- **情境 × 正式程度**：4 種情境、每種 3 種正式程度，共 12 份手寫範本。
- **對象關係自動代換**：依初次接觸／長期往來／上級或重要客戶，自動替換對應的敬語句子。
- **原因/補充說明選單**：依情境提供對應的常見原因（如排程已滿、原物料短缺、價格無法達成等），選了會自動把具體數字、日期代入範本正文。
- **情境誤選提醒**：以關鍵字比對你輸入的內容與選擇的情境是否相符，偵測到可能選錯時會先提醒、需要再次確認才會產生草稿（支援中英文）。
- **敬語等級標註**：每份草稿都附上重點敬語用法說明，方便你理解、學習日文商務書信的禮貌層級。

## 與直接跟大型語言模型對話的差異

直接與一般大型語言模型（LLM）對話時，模型並不會主動評估「你與客戶之間的關係該如何維繫」——它只會依照你輸入的內容逐字生成或翻譯。也就是說，如果你輸入的原始想法用詞直接、甚至帶有情緒，模型往往會把這樣的語氣原封不動地反映在輸出內容裡，而商務書信一旦措辭失當，很容易對客戶關係造成不必要的傷害。

本工具的設計邏輯不同：你輸入的內容**只作為你自己事後對照填空的參考**，不會被直接拿去生成或翻譯成信件正文。日文正文是在你選定「情境類型」「對象關係」「正式/委婉程度」等框架後，套用事先撰寫、反覆校對過的固定範本——即使你當下輸入的想法再直接，輸出都會被限制在商務書信應有的分寸與禮貌之內，相較於直接與 LLM 對話，更不容易因為一時措辭而出錯。

### 範例

**輸入（想表達的事）**：
> 這個價格也太低了吧，無法承接，拒絕

**設定**：情境類型「拒絕」、對象關係「初次接觸」、正式/委婉程度「一般丁寧」、原因/補充說明類型「不特別套用」

**輸出**：

```
件名：ご提案についてのご回答

○○株式会社　○○様

お世話になっております。株式会社△△の◇◇です。

初めてのお取引でのご提案であったにもかかわらず、ご提案いただきました件につきまして、社内で検討いたしましたが、
誠に恐縮ながら今回はご要望にお応えすることが難しい状況でございます。

何卒ご理解いただけますと幸いです。
今後とも何卒よろしくお願い申し上げます。
```

即使原始輸入的語氣直接、甚至帶有情緒性的用詞，輸出仍會被固定框架限制在商務應有的委婉分寸內，不會把你當下輸入的語氣或措辭直接帶入客戶會看到的正式文件。

## 技術說明

- 純 HTML + CSS + 原生 JavaScript（無框架、無建置流程）。
- 所有範本、敬語標註、原因選單皆為程式內的靜態資料，直接修改 `index.html` 即可調整文字或新增情境。

## 關於本工具

本工具提供的是通用型日文商務書信範本架構，涵蓋道歉、報價、催交期、拒絕四種常見商務情境。在實際調整與測試的過程中，我們也觀察到：真實商業情境往往充滿個案差異，很難單靠固定範本完整涵蓋所有狀況。
